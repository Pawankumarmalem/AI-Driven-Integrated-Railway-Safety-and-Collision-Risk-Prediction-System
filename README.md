# AI-Driven-Integrated-Railway-Safety-and-Collision-Risk-Prediction-System
An AI-driven railway safety prototype integrating ESP32-based multimodal sensing, YOLO object detection, and collision-risk assessment with a real-time web dashboard for obstacle monitoring and safety alerts.
## Project Screenshots

### Hardware Implementation

The physical railway safety prototype integrates ESP32-based sensing modules with a model railway track for obstacle monitoring and safety alerts.
